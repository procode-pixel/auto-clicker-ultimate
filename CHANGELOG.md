- Analytics page draws a real session bar chart from stored click counts (last 24 sessions). Empty until a session finishes. ASCII bars in the history list remain.

## 1.0.0

First release of Auto Clicker Ultimate.

- Click engine with buttons, sequences, intervals, positions, delay, and schedule.
- Macro recorder and editor, workflow builder, pixel and image checks.
- Profiles, hotkeys, tray, analytics, English and Arabic.
- Safety ceilings, emergency latch, and strict JSON import.
- Windows zip built by GitHub Actions.
